YOUR OWN VOICE RECORDINGS
=========================

Drop MP3 files in the two folders below, using EXACTLY these names.
If a file is missing, that one sound is simply skipped (the soft music
and chimes still play). You can add them one at a time, in any order.

Folder audio/letters/   (what the child hears when a letter or number opens)
  a.mp3 b.mp3 c.mp3 ... z.mp3                 the CAPITAL letters, e.g. "De A"
  a-klein.mp3 b-klein.mp3 ... z-klein.mp3     the SMALL letters, e.g. "De kleine a"
  0.mp3 1.mp3 2.mp3 ... 9.mp3                 the numbers, e.g. "De twee"

  What you say in each file is up to you, e.g. "De M... mmm".
  File names are all lowercase.

Folder audio/phrases/
  welkom.mp3     when a child picks their cat      e.g. "Hoi! Leuk dat je er bent!"
  kies.mp3       when the choice screen opens      e.g. "Wat gaan we oefenen?"
  kijk.mp3       before the cat shows the stroke   e.g. "Kijk, zo gaat het!"
  hoeveel.mp3    counting game, each new round     e.g. "Hoeveel zijn het?"
  wissel.mp3     when it is the other cat's turn  e.g. "Tijd om te wisselen!"
  meer.mp3       maths game, "more" round           e.g. "Waar zijn er meer?"
  erbij.mp3      maths game, "adding" round         e.g. "Hoeveel zijn het samen?"
  goed-1.mp3 ... goed-5.mp3        after a success   e.g. "Goed zo!", "Super!", "Wat knap!"
  nogeens-1.mp3 ... nogeens-3.mp3  after a try that did not work   e.g. "Probeer het nog eens!"

Optional: your own engine sound for the bonus ride
  audio/ride/engine.mp3   a short engine loop (1-3 seconds) that repeats smoothly.
  The game speeds it up and slows it down with the car. If the file is missing,
  the game uses its own made-up engine sound.

Tips: keep each clip short (1-3 seconds), record in a quiet room, and use
a cheerful voice. After adding files, reload the page once while online.
